# 藍牙借車實機測試

正式版與 debug 版都會在按「出發」後觀察新的藍牙連線：名稱以 `EYB` 開頭就立即標記「已借車」，借車站使用目前選取的站點。`EYB` 不代表電輔車；使用者已確認最新樣本為一般車。Android 12 起需要「附近裝置」權限。拒絕權限時仍可手動借車。

切換到 YouBike App 後，前景服務會繼續等待；借車、取消通勤、關閉藍牙或移除 App 工作時停止。處理程序終止後不自行重啟，重新開啟 YouCommuter 可恢復尚未借車的通勤偵測。不掃描、不主動連線；已存在的連線快照不觸發借車，斷線不代表還車。還車仍需手動確認。

以下是 **debug 版觀察工具** 的操作。工具本身只記錄事件與人工標記；若同時有通勤，獨立運作的自動借車服務仍會更新通勤狀態。

## 操作

1. 安裝 debug APK，不需後端、路線或 YouCommuter 帳號。
2. 點通勤頁右上角的「借車測試」圖示。若當時有通勤，測試會綁定該通勤；沒有通勤也能獨立觀察。
3. 點「開始」，允許「附近裝置」。Android 13 以上另可允許通知，方便從通知停止測試；拒絕通知仍可在頁面停止。
4. 看到「藍牙觀察中」後，點 **YouBike** 切換官方 App，照平常方式掃碼借車。
5. 回到測試頁，標記「借車成功」或「借車失敗」。臨停、還車也可標記。這些按鈕只記錄按下的時間，不是車鎖或付款結果的驗證。
6. 點「停止」再「匯出」，自行選擇 JSON 儲存位置。若通勤已結束，也可從右上角進入測試頁匯出；請在按通勤「完成」清除畫面前匯出。測試頁的「清除」可移除記憶體中的結果。

連線事件旁的展開圖示可查看名稱、類型、分類與快取 UUID。請在連線前先開始觀察；連線、斷線和初始連線快照會各自讀一次當時的系統快取，不會等待斷線或額外掃描。事件時間取自收到廣播時，早於快取讀取；這不是車鎖精確操作時間。

可先在同一站短程測試，讓借還車落在 15 分鐘的觀察上限內。返回主畫面、切換 App 不會停止前景服務；綁定的通勤結束、藍牙關閉、權限失效、移除 YouCommuter 工作或處理程序終止會停止。獨立觀察不受通勤變更影響。處理程序終止後資料不保留。

## 要比對的情境

| 情境 | 要確認的訊號 |
|---|---|
| 掃碼成功 | 是否收到 LE 連線、多久後斷線、是否在取車前就斷線 |
| 掃碼失敗、取消、重試 | 是否也出現相同的短暫連線 |
| 同一台車臨停與再解鎖 | 是否再次連線，是否容易被誤當成新租借 |
| 騎乘與還車，官方 App 在背景／已關閉 | 是否有額外事件；沒有事件也是有效觀察 |
| 原有耳機、手錶或其他藍牙 App | 是否出現無關裝置，與車機事件能否區分 |

建議同時記下 Android、YouBike App 版本、手機型號、2.0 或 2.0E 車種，以及操作與標記的時間差。先保留不確定性，不要把人工標記當成車鎖的精確時間。

## 資料與限制

- 只讀系統 GATT 連線快照、ACL 事件與裝置快取，不掃描、不配對、不探索服務、不主動連車，也不送出借車指令。權限仍只有既有的藍牙連線權限，不新增掃描或定位權限。
- JSON `schemaVersion` 為 2。事件含相對時間、事件類別、連線傳輸類型、當次測試的「裝置 1／2」代號，以及 `deviceInfo`。代號只在同一段測試中可比較。
- `deviceInfo` 含 `name`、`cachedServiceUuids`、`type`（Unknown／Classic／LowEnergy／Dual）及 `bluetoothClass`（Android `BluetoothClass.getDeviceClass()` 的整數值）。UUID 是快取，不保證完整；`null` 表示未知或讀取失敗，`[]` 表示讀到空列表。名稱移除控制字元並限制為 248 個字元；UUID 去重、排序，最多保留 64 個。每筆事件保留自己的快照，不用斷線時的資料回填連線事件。
- 不輸出裝置地址欄位、驗證碼、廣播封包、定位、帳號或路線／通勤識別碼；不自動上傳。匯出現在包含裝置名稱，可能帶有使用者自訂或可辨識資訊。
- 每次最多 200 筆事件、64 個裝置；新測試會取代上一段已停止的結果。
- `EYB` 開頭的名稱在事件列顯示自行車圖示，這是目前採用的產品辨識假設。原始 JSON 保留當次系統快取，不另存可由名稱推導的分類。
- 尚未接上位置與活動辨識，也未實作自動還車。正式 release 版不包含觀察工具的入口與服務，但包含通勤用的藍牙借車偵測與權限。

## 建置與驗證

使用專案既有的 JDK 21 / Android SDK 37：

```sh
cd android
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK：`android/app/build/outputs/apk/debug/app-debug.apk`。詳細靜態研究見 [YouBike 借還車偵測研究](RIDE_DETECTION_RESEARCH.md)。
